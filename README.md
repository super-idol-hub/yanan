# 颜安 · Windows 互动角色

由 **Anbunensi** 制作的颜安粉丝向桌面互动角色。免费、非官方、非商业。

> 双皮肤候选版已通过资源和 Windows 自动交互验证。干净 Windows 10/11 人工验收尚未完成，尚未正式发布。详情见 [QA 报告](docs/QA_REPORT.md)。

<img src="docs/visual/noir-anchor-v2.png" alt="修正比例的黑白日常造型" width="264"> <img src="docs/visual/stage-anchor-v1.png" alt="银曜舞台造型" width="264">

按 [Super Idol Hub Windows 互动角色开发规范](https://github.com/super-idol-hub/idol-windows-character-guides) 制作。一个 EXE 内置“黑白日常”和“银曜舞台”两套完整造型；每套 24 行、176 张 528 × 808 RGBA 关键帧和 315 组双向动作网格。

两套造型均已调整头身比、腰线和腿部比例。手机动作坐定后低头看屏幕，固定姿势和大小，点击后起身。

支持拖动受惊与松手恢复、双击挥手、16 方向凝视、随机待机、舞蹈、舞台、持久手机与睡眠动作、托盘、125%–400% 缩放和当前用户开机启动开关。开机启动默认关闭，角色不自动在桌面漫游。
