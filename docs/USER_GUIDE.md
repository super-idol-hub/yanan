# 颜安互动角色使用说明

正式版本发布后，从本仓库 Releases 下载 EXE 或完整 ZIP。解压 ZIP 后双击 `yanan-1.0.0.exe`，角色会出现在屏幕右下角。无需安装 Python、OpenCV 或开发工具。

- **拖动**：按住角色移动；开始拖动时会受惊，松手后恢复。
- **挥手**：双击角色。
- **凝视**：把鼠标移到角色附近，视线会跟随；移远后恢复待机。
- **更多动作**：右键打开动作菜单，可选择舞蹈、舞台表演、手机、睡眠等。
- **手机**：动作持续保持，单击后收起手机并起身。
- **睡眠**：单击或按键唤醒。
- **大小**：滚轮每次调整 25%，范围 125%–400%。
- **皮肤**：右键“皮肤”选择内置造型；首发包含“黑白日常”。
- **暂停与置顶**：在右键菜单中切换。
- **开机自启**：默认关闭。在右键菜单中勾选开启，取消勾选关闭，只影响当前 Windows 用户。
- **显示位置**：双击托盘图标使角色显示并回到右下角。
- **退出**：右键“退出”，或角色获得焦点时按 Ctrl+Q。

角色找不到时，可双击通知区域的托盘图标。请勿同时启动多份程序。若系统阻止运行，请保留提示内容并联系维护者，不要关闭系统安全保护。
