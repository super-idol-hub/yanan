# 权利与隐私

本项目免费、非官方、非商业，仅供粉丝个人欣赏、学习与交流。开发者：Anbunensi。

颜安的姓名、肖像、服装设计及相关权利属于各自权利人。本软件不表示艺人本人、工作室、经纪公司、品牌或平台认可，也不声称取得其书面授权。不得收费分发、二次售卖、冒用官方名义或用于商业推广。权利人提出合理请求时，应及时下架或调整。

角色与动作是 AI 辅助创作。原始参考照片、视频、音频、歌词和商业字体不进入源码或发布包；程序不使用艺人录音或声音克隆。

程序不主动联网，不收集遥测。皮肤选择和开机启动偏好保存在当前用户的本地应用数据中。开机启动默认关闭，仅由用户菜单操作写入当前用户 Run 注册表项；可随时关闭，不需管理员权限。测试使用隔离设置文件，不修改真实开机启动项。
